# Corporate Finance Valuation, M&A & LBO Analysis

An integrated corporate finance modeling project covering **DCF valuation, WACC, comparable company analysis, M&A transaction modeling, accretion/dilution analysis, synergy analysis, and LBO modeling**.

## Project Overview

This project demonstrates the application of core corporate finance and investment banking techniques to analyze companies in the European chemicals sector.

The model combines historical financial data, valuation methodologies, transaction assumptions, financing structures, and sensitivity analysis to evaluate company valuations and potential acquisition scenarios.

## Companies Analyzed

* BASF
* Covestro
* Evonik Industries
* Arkema
* Solvay

## Financial Modeling Components

### 1. DCF Valuation

The DCF model includes:

* Revenue and operating forecasts
* Unlevered Free Cash Flow (UFCF)
* Weighted Average Cost of Capital (WACC)
* Terminal Value
* Enterprise Value
* Net Debt
* Equity Value
* Implied Share Price
* WACC / Terminal Growth sensitivity analysis

### 2. Comparable Company Analysis

The comparable company analysis evaluates the selected companies using:

* Enterprise Value
* Revenue
* EBITDA
* EV / Revenue
* EV / EBITDA
* Median trading multiples

### 3. M&A Analysis

The M&A model evaluates a hypothetical acquisition of **BASF by Covestro** and includes:

* Acquisition premium
* Offer price per share
* Equity purchase price
* Enterprise value
* Existing debt / refinancing
* Transaction fees
* Sources & Uses
* Cash, debt and equity financing
* Revenue and cost synergies
* Pro forma income statement
* Accretion / dilution analysis
* Acquisition premium sensitivity analysis

### 4. LBO Analysis

The LBO model includes:

* Entry valuation
* Sources & Uses
* Debt financing
* Sponsor equity contribution
* Operating projections
* Cash flow available for debt repayment
* Debt paydown
* Interest expense
* Exit valuation
* Exit equity value
* Sponsor returns
* MOIC
* IRR
* LBO sensitivity analysis
